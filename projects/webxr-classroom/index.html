Building an immersive classroom experience in the browser.

This prototype explores how browser-based 3D environments can support more immersive learning through space, interaction, animation, sound and multimedia.

01

Project overview

I built a virtual learning environment in Three.js, designed as an interactive WebXR classroom with animated characters, classroom objects, lighting, multimedia content and controller-based interaction.

The scene opens from the back of the classroom, with desks, a projector screen, textured flooring, light grey walls, a bookshelf and animated characters.

3D Scene

Classroom environment, desks, projector, screen, bookshelf and characters.

WebXR

VR headset positioning, controller setup and raycasting interaction.

Multimedia

Video texture on the projector screen and spatial teacher audio.

Debug Tools

lil-gui controls and stats.js for real-time performance monitoring.

02

WebXR interaction

I integrated WebXR using the Immersive Web Emulator, VRButton, controller models and headset positioning.

One challenge was that the headset position did not match the original camera position at first, so I had to manually adjust the setup to keep the VR view aligned.

I also implemented raycasting interaction. When the controller ray hits a test cube and the user presses a button, the cube changes colour and can be moved around the scene.

03

Multimedia & technical build

To make the classroom feel more like a learning environment, I added a video lesson onto the projector screen using a video texture mapped onto a Three.js plane.

I also integrated spatial teacher audio, so the sound changed depending on the user’s position in the room.

The scene combined multiple light types, shadows, imported models, shader-based objects, lil-gui controls and stats.js performance monitoring.

04

Reflection

This project helped me understand how many systems need to work together inside an interactive 3D experience: scene structure, lighting, models, animation, camera controls, shaders, audio, video and WebXR interaction.

The most valuable part was learning how to debug immersive interaction, especially when the browser view, headset position and controller behaviour did not immediately match.
