01

Project overview

Ready Buddy is a gamified educational app designed to help children learn how to react in everyday emergency situations.

The project explores how interaction design, playful learning and mobile games can make safety education feel clearer, calmer and more memorable. The final prototype focuses on the Junior Squad section for children aged 6–10.

02

Product experience

The app combines short safety games, instruction screens, progress-based navigation, audio feedback and a final quiz structure.

My goal was to avoid overwhelming children with information and instead create a friendly space where they could learn by doing.

I worked across the full process: research, app structure, visual identity, UX/UI design, SwiftUI development and Unity integration.

03

Technical approach

Ready Buddy was built mainly in SwiftUI, with reusable components, structured navigation and native game screens forming the core of the Junior Squad experience.

One Unity mini-game was integrated into the iOS app through the Xcode workspace, requiring communication between Unity’s C# environment and the SwiftUI app structure.

Because the Unity/Xcode integration was unstable and time-consuming, I kept one Unity game in the final prototype to demonstrate hybrid integration, while building the remaining games natively in SwiftUI.

04

Scout AI chatbot

Ready Buddy also includes Scout, an AI chatbot designed as the Junior Squad’s guide. Scout gives short, child-friendly answers to app-related questions.

The chatbot was embedded in SwiftUI using WebKit’s WKWebView and a JotForm AI agent. I also injected CSS after load to remove unnecessary web interface elements and keep the experience focused.

Scout used a custom knowledge base with no open web access, keeping responses limited to age-appropriate Ready Buddy content.

05

Reflection

This project taught me how to manage a larger technical build, structure a multi-section app, debug complex integrations and balance educational goals with playful interaction design.

If I developed it further, I would focus on real user testing, a stronger design system from the beginning and expanding the app beyond the Junior Squad.
