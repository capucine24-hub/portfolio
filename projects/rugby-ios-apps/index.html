01

Why rugby?

Rugby made the assignments feel more personal than a generic app exercise. I wanted the apps to feel like small rugby tools, with structured player lists, team sections, profile views, favourites and editable records.

This project also connects to one of the direction I want to move towards: building digital products and interactive experiences for sport.

Assignment 1

XML Parsing

A UIKit app that reads rugby player data from XML and displays it in team-based sections.

Assignment 2

Core Data

A persistent iOS app where users can add, edit, delete, favourite and manage players locally.

02

XML Parsing App

The first app was built with Swift, UIKit and Storyboard. It parsed rugby player data from XML and displayed players in a native table view interface.

Players were organised into team sections, sorted alphabetically and styled dynamically using attributes such as nationality and colour values from the XML file.

XMLParser

Loaded rugby player data and converted XML into structured app data.

Team Sections

Grouped players by team to make the table view easier to scan.

Dynamic UI

Used player attributes to change cell colours, image borders and detail styling.

03

Core Data App

The second app extended the rugby player concept with Core Data, allowing player records to be created, edited, deleted, saved and favourited locally.

Initial player data was imported from XML when Core Data was empty, while manually added records could be updated by the user through the app.

Core Data

Persisted players locally and saved edits, new records and favourite states.

CRUD Flow

Users could create, read, update and delete manually added player records.

Swipe Actions

Swipe gestures allowed users to favourite, unfavourite or delete players.

Protected Records

XML-sourced players were protected from deletion to preserve the original dataset.

Image Handling

Player images could be loaded, saved, resized and displayed across the app.

Live Updates

Fetched results helped keep table views updated when Core Data changed.

04

What I learned

These assignments helped me understand how much mobile app design depends on data structure: parsing, grouping, sorting, editing, saving and updating content across screens.

I also practised safer development habits, including validating URLs, handling invalid data, protecting imported records and keeping navigation clear after user actions.
