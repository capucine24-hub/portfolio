Sketch 1 — Collision + Easing

A moving circle follows the mouse using lerp-based easing, then changes state when it collides with fixed circles.

01

Sketch 1 — Collision + Easing

The first sketch combines eased motion with real-time collision detection. Six fixed circles are generated on load, while a second circle follows the mouse using lerp-based easing.

Each frame, the sketch calculates distance between the moving circle and the fixed circles. When a collision happens, the moving circle changes state and freezes in place.

02

Sketch 2 — Generative Bubbles

The second sketch is an object-oriented particle system made of independent bubble objects, each with its own position, size, growth rate, colour and opacity.

The bubbles drift, grow, fade and reset over time, creating a small interactive generative system with fullscreen and Start/Stop controls.

View Sketch 2 in p5.js editor

03

Sketch 3 — Interactive 3D Scene

The third sketch moves from 2D generative visuals into a real-time 3D scene using p5.js WEBGL mode.

Four primitives are built from a shared parent class using inheritance. The viewer can orbit the camera, select objects, reshape them with a slider and adjust colours through live controls.

View Sketch 3 in p5.js editor

Reflection

These sketches helped me understand how small mathematical rules can create clear interactive behaviour on screen.

Together, they show the beginning of my creative coding practice: using code not only to display visuals, but to create movement, behaviour and interaction.
