01

Project overview

Career Filter is a self-generated web tool designed to help users gain career clarity by progressively filtering out unwanted paths.

Instead of asking users to define the perfect direction straight away, it helps them start from what they already know they do not want.

Insight

It can be easier to reject what feels wrong than to name what feels right.

Interaction

Users remove unwanted options until clearer patterns emerge.

Outcome

The tool turns uncertainty into a more manageable decision process.

02

Interaction model

The interface was designed to feel simple, direct and low-pressure, turning uncertainty into a focused decision flow based on elimination.

I built the prototype using HTML, CSS and JavaScript, connecting the concept directly to the filtering logic and user interaction.

03

Reflection

This project taught me that useful digital tools do not always need to be complex. A strong concept and a clear interaction model can be enough to make a small prototype meaningful.

If I developed it further, I would add more personalised results, clearer user pathways and a stronger visual summary at the end of the filtering process.
